Xerxes is different.

[1 · voice, ~8 s] First, it’s truly voice-native, with generative UI: anything you can do over chat, you can do over voice, and the cards draw themselves as it talks. It’s a real conversation: cut in, follow up, or paste a product link and it reads the page.

[2 · reaches out] It initiates. It has your projects and your calendar, and keeps running on its own, so it brings up the birthday before you ask.

[3 · legwork] It does the legwork: compares prices, checks delivery against your deadline, looks at reviews, and suggests a shop nearby when it has to be today.

[4 · project] It knows the project. Furnishing your living room? You already have the sofa and the rug, so it recommends what’s missing.

[5 · calendar] And it knows your calendar and budget, and reminds you to buy gifts, with ideas from each person’s profile.

[Step 1 holds about 8.5 s, the others about 6.5 s. A click skips to the overview; the next click moves on. K (or the pause button by the countdown) pauses the tour, then each click shows the next step. Photos and reviews are live: attach a photo in chat and the agent sees it; reviews come from the agent’s live web search. Both run through the user’s own authorized agent. Paste a product link and Codex opens the page.]

Appendix · Q&A

What’s live, what’s next.

Live

  • Voice calls on Agora ConvoAI with Murf Falcon, cards drawn mid-call
  • Live searches, prices and delivery dates as each retailer states them
  • Shops nearby from OpenStreetMap, on a map
  • Background jobs: occasion nudges, gift ideas, game and hardware watches

Remembers

  • People you shop for and what it learns about them
  • Its own calendar: occasions, budgets, arrive-by dates
  • Projects: what you have, bought and plan, and budget left
  • Photos and product links in chat; reviews checked as it shops

Next

  • Google Drive backup (today: a local file)
  • Other MCP agents as the brain, not only Codex
  • Price watches for any product; checkout in the app

Run itThe README has every step.

# Node 24+, the Codex CLI (codex login), cloudflared for voice
node scripts/sync-secrets.mjs                   # keys → backend/.env, values never printed
cd backend && npm install && npm run dev        # http://localhost:8787
cloudflared tunnel --url http://localhost:8787  # then set PUBLIC_URL
